# Website Thương Mại Điện Tử CameraShop (E-commerce) 📸

Đây là source code Đồ án Thực tập Tốt nghiệp của mình. Dự án xây dựng một nền tảng mua bán máy ảnh với đầy đủ phân hệ quản lý cho Khách hàng và Admin.

## 🌐 Trải nghiệm hệ thống thực tế (Live Demo)
👉 **Link Website:** [Bấm vào đây để xem hệ thống đang chạy](https://camerashop-frontend-y0hn.onrender.com)

## 🛠️ Công nghệ sử dụng
* **Front-end:** ReactJS (Vite), Tailwind CSS
* **Back-end:** NodeJS, ExpressJS
* **Database:** MySQL, Prisma ORM
* **Deploy:** Render & Aiven Cloud
